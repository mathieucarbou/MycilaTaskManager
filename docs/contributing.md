# Contributing

## Development Setup

```bash
git clone https://github.com/mathieucarbou/MycilaTaskManager.git
cd MycilaTaskManager
pio run
```

The examples are compiled by switching `src_dir` in `platformio.ini`:

```ini
[platformio]
lib_dir = .
src_dir = examples/TaskManager   ; AsyncTaskManager, Json or Watchdog
```

## Building the Documentation

The website is built with [MkDocs](https://www.mkdocs.org/) and the [Material](https://squidfunk.github.io/mkdocs-material/) theme. The C++ API is generated by Doxygen through the [mkdoxy](https://github.com/JakubAndrysek/mkdoxy) plugin.

```bash
python3 -m venv venv
source venv/bin/activate
pip install mkdocs-material mkdoxy

mkdocs serve   # local preview on http://127.0.0.1:8000
mkdocs build   # static site in ./site
```

`doxygen` must be installed and on your `PATH` for the `cppapi` section to be generated.

## Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Commit your changes: `git commit -m 'Add my feature'`
4. Push to the branch: `git push origin feature/my-feature`
5. Open a Pull Request
